# Une page

## Créer un site à l'étage

Rôle : `editor` ou `admin`.

Ouvrez **Sites**, puis **Nouveau site**. Le bouton **Enregistrer** crée le site, et le message **3 sites créés** le confirme ; avec un seul, **1 site créé**. La liste **Aucun site** reste vide sinon.

Voir [**Sites**](autre.md) et [la section suivante](#créer-un-site-à-létage-1).

| Colonne | Libellé   |
| ------- | --------- |
| Statut  | **Prévu** |

Dans du code, ni `**Inventé**`, ni `__Inventé__`, ni `[ce lien](absent.md)` ne comptent.

```text
**Inventé** et [lien](absent.md) dans un bloc de code.
```
